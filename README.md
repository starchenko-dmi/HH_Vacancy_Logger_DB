# HH Vacancy Logger DB

**Сервис для автоматизированного сбора и аналитического анализа вакансий с платформы hh.ru.** Позволяет получать актуальные данные о работодателях, структурированно хранить их в PostgreSQL и получать аналитику по зарплатам через удобный консольный (CLI) интерфейс.

## 📋 Описание функционала

Проект реализует полный цикл ETL (Extract, Transform, Load) для аналитики рынка труда:
- **Сбор данных**: Автоматическая загрузка информации о компаниях и их вакансиях (до 2000 на работодателя) через официальное API hh.ru.
- **Rate-limiting**: Встроенные задержки (0.2 сек) между запросами для соблюдения лимитов API и корректный `User-Agent`.
- **Идемпотентная загрузка**: Использование `ON CONFLICT DO NOTHING` гарантирует отсутствие дубликатов при повторных запусках скрипта.
- **Аналитический CLI-интерфейс**:
  1. Рейтинг компаний по количеству открытых вакансий.
  2. Полный список всех вакансий с указанием зарплатных вилок.
  3. Расчет средней зарплаты по рынку (с корректной обработкой неполных данных).
  4. Фильтрация вакансий с зарплатой выше средней.
  5. Поиск вакансий по ключевому слову в названии.

## 🏗 Архитектурные решения и особенности проекта

### Структура базы данных
Проект использует нормализованную реляционную схему с двумя основными таблицами:
- **`employers`**: `employer_id` (PK), `name`, `url`, `open_vacancies`.
- **`vacancies`**: `vacancy_id` (PK), `employer_id` (FK с `ON DELETE CASCADE`), `name`, `salary_from`, `salary_to`, `currency`, `url`.

### Ключевые технические решения
1. **Модульная архитектура**: Четкое разделение ответственности:
   - `src/api/hh_api.py`: Инкапсуляция логики взаимодействия с внешним REST API (библиотека `requests`).
   - `src/db/db_creator.py`: Управление схемой БД (создание БД через `ISOLATION_LEVEL_AUTOCOMMIT`, создание таблиц).
   - `src/db/db_manager.py`: Класс `DBManager` для выполнения аналитических SQL-запросов.
2. **Обработка "грязных" данных**: В расчетах средней зарплаты используется SQL-функция `COALESCE`, чтобы корректно обрабатывать вакансии, где указана только граница "от" или только "до".
3. **Безопасность и конфигурация**: Чувствительные данные (пароли, хосты) вынесены в переменные окружения через `python-dotenv`.

## 🛠 Стек технологий

- **Python 3.11+**
- **PostgreSQL** (реляционная СУБД)

## 🚀 Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/starchenko-dmi/HH_Vacancy_Logger_DB.git
cd HH_Vacancy_Logger_DB
```

### 2. Настройка окружения
Установите зависимости с помощью Poetry (рекомендуется) или pip:
```bash
# Через Poetry
poetry install

# Или через pip
pip install -r requirements.txt
```

### 3. Конфигурация переменных окружения
Создайте файл `.env` на основе шаблона `.env.example`:
```bash
cp .env.example .env
```
Заполните его данными для подключения к вашей локальной базе данных PostgreSQL:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=your_secure_password
```

### 4. Запуск приложения
```bash
python main.py
```
*При первом запуске скрипт автоматически создаст базу данных `hh_vacancies` (если её нет), развернет схему таблиц и начнет загрузку данных.*

## 💻 Примеры использования (CLI)

После запуска открывается интерактивное меню:
```text
Выберите действие: 
1. Список компаний и количество вакансий 
2. Все вакансии 
3. Средняя зарплата 
4. Вакансии с зарплатой выше средней 
5. Поиск вакансий по ключевому слову 
0. Выход 

Ваш выбор: 
```

**Пример 1: Рейтинг компаний (Выбор `1`)**
```text
Яндекс: 342 вакансий
Сбер: 287 вакансий
Тинькофф: 156 вакансий
```

**Пример 2: Средняя зарплата (Выбор `3`)**
```text
Средняя зарплата: 185000.00 руб.
```

**Пример 3: Поиск по ключевому слову (Выбор `5`)**
```text
Введите ключевое слово: python
Яндекс — Python Developer | от 150000 до 250000 | https://hh.ru/vacancy/...
Ozon — Senior Python Backend | от 250000 до 400000 | https://hh.ru/vacancy/...
```

## 📁 Обязательные технические файлы и практики

В репозитории соблюдены стандарты профессиональной разработки:
- **`.gitignore`**: Исключает конфиденциальные данные (`.env`), байт-код (`__pycache__`), логи и настройки IDE (`.idea/`, `.vscode/`).
